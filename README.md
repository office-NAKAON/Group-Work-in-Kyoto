# 京都班別自主研修 探究ワークシート

中学2年生が、班で相談しながら一人ひとりの用紙に記入する探究ワークシートです。
分野と対象の選択から、問い、予想、現地で確かめること、調べ方と訪問候補、役割分担までを8ステップで進めます。

## 印刷用PDF

`output/pdf/` に収録しています。

- `京都探究ワークシート_京都探検マップ風_A3横1枚.pdf`：水彩調の京都イラスト付き。A3横1枚。
- `京都探究ワークシート_冒険ボードゲーム風_A3横1枚.pdf`：鮮やかな京都イラスト付き。A3横1枚。
- `京都イラスト版`：各デザインのA4縦2ページ版。
- その他のPDF：背景イラスト追加前のA4縦2ページ版。

A3版はA3用紙、横向き、カラー、片面で印刷してください。

## 生成ファイル

Pythonと `reportlab`、`pypdfium2`、`pypdf` を使用します。
日本語フォントとしてWindowsの `C:/Windows/Fonts/YuGothM.ttc` と `YuGothB.ttc` を参照します。
別の環境ではフォントのパスを調整してください。

リポジトリのルートから、目的に応じて実行します。

```powershell
python make_worksheets.py
python make_worksheets_illustrated.py
python make_a3_worksheets.py
```

背景画像は `output/assets/` に収録しています。画像生成ツールで、水彩調の京都探検マップ背景と、カラフルな京都冒険マップ背景を作成しました。共通の指定は、五重塔・鳥居・町家・竹林・抹茶・八つ橋などを外周に配置し、中央は記入欄用に空け、画像内には文字を入れないことです。

`tmp/` は生成時の確認用ファイルであり、コミット対象に含めません。
